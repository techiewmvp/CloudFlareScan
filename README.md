🚀 高效扫描：内置CloudFlare官方CIDR段生成的IP地址 还可以导入自定义TXT格式的CIDR文件覆盖内置IP

📊 双模式测速：完全测速 + 地区测速，满足不同需求

🌍 全球覆盖：内置全球大部分机场IATA代码映射，自动识别地区

⚡ 全端口处理：支持全端口同时高并发测试，单端口最大线程可达32快速获取全端口测试结果，也可直接在测速结果窗内单独复制

📋 一键导出：单击导出结果即可生成当前测速结果CSV文件，包含端口、地区码、延迟、下载速度以及测速类型

📈 实时统计：实时显示扫描进度、速度

使用方法：

CloudFlareScan-Windows.zip 直接下载使用
